# Canton Network — deployment status

Status: Canton MainNet is documented as the production environment and the Foundation publishes current MainNet Super Validator information. Individual application deployment status remains application-specific.

## Network deployment
- Canton documentation distinguishes DevNet, TestNet, and MainNet. The Canton Foundation's SV Network Status page has a MainNet deployment-information area and lists MainNet Super Validator node information.
- The Canton Foundation describes MainNet as the production environment for Super Validators, Validators, and App Operators. TestNet is described as the pre-production environment for testing upgrades and long-running application instances.
- Canton Network's official FAQ names institutional applications/platforms such as Goldman Sachs DAP, Broadridge DLR, and Versana as examples of applications built and used on Canton. This is an official ecosystem claim; this research has not independently audited each application's precise production scope or launch status.
- Validator access remains subject to the current onboarding model: the FAQ says anyone can request a validator node, but sponsorship is currently needed.

## Evidence
1. [Canton Foundation — SV Network Status](https://canton.foundation/sv-network-status-2/)
2. [SV Operated networks and use-cases](https://docs.global.canton.network.sync.global/app_dev/testing/networks_and_usecases.html) — describes DevNet, TestNet, and MainNet roles, with MainNet as production.
3. [Canton Network FAQ](https://www.canton.network/faq) — validator sponsorship and official application examples.
4. [Canton Foundation — Validators](https://canton.foundation/validators/) — validator onboarding and Node-as-a-Service options.

## Interpretation limits
- The evidence supports a live production MainNet for Canton infrastructure. It does not prove every Canton application is live in production.
- The presence of DevNet and TestNet does not make MainNet a test environment.
- Treat individual application claims and network-wide deployment status as separate evidence items.
