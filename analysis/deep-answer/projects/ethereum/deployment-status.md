# Ethereum — deployment status

Status: Ethereum Mainnet is a live public production network. The status of a particular privacy application must be assessed separately from the status of the base chain.

## Network deployment
- **Ethereum Mainnet:** official Ethereum documentation describes Mainnet as the primary public production blockchain where transactions involving assets of actual value are recorded.
- **Sepolia:** a public testnet intended for application development. Ethereum's documentation says Sepolia uses a permissioned validator set controlled by client and testing teams.
- **Hoodi:** a testnet for protocol-upgrade and validator-operation testing.
- Mainnet production status does not mean every application deployed on Ethereum is production-ready, permissionless, or private.

## Institutional evidence within scope
- Visa announced in March 2021 a pilot with Crypto.com and Anchorage to use USDC over Ethereum to settle part of Crypto.com's Visa card-program obligations. Visa's announcement defines the settlement as partner settlement over VisaNet, not a consumer-to-merchant payment. This is evidence of a specific historical institutional pilot, not evidence that all Visa settlement runs on Ethereum.
- Visa's April 2026 stablecoin-settlement announcement says its multi-chain pilot supports nine blockchains, including Ethereum. The announcement does not assign every partner or settlement flow to a specific chain.
- These examples demonstrate that public-chain infrastructure has been explored/used in institutional settlement workflows; they do not make Ethereum's base layer confidential.

## Evidence

2. [Visa, USDC settlement over Ethereum (2021-03-29)](https://usa.visa.com/about-visa/newsroom/press-releases.releaseld.17821.html) — specific historical pilot scope.
3. [Visa, multi-chain stablecoin settlement expansion (2026-04-29)](https://corporate.visa.com/en/sites/visa-perspectives/newsroom/visa-expands-stablecoin-settlement-adds-five-blockchains.html) — lists Ethereum among the nine supported chains in Visa's pilot.

## Interpretation limits
- Ethereum Mainnet's live production status is a base-network fact; it does not prove a named privacy system on Ethereum has the same production status.
- The Visa 2021 announcement describes a pilot and partner settlement obligations; do not rewrite it as consumer payments settling on Ethereum.
- The 2026 Visa release describes a multi-chain program, not a statement that each listed chain carries every partner's settlement.
